# prettier PWA

手机上用的应用：拍照、记一条、看时间线和趋势。

**这个目录里没有任何个人数据**，只有代码。照片和记录都在你自己的 Cloudflare 上
（见 `../api/`），要口令才能读。这个目录由 Worker 直接托管，不需要 GitHub 仓库。

## 文件

- `index.html` —— 应用入口（口令页 + 四个视图）
- `assets/app.css` —— 样式，支持浅色/深色/跟随系统
- `assets/app.js` —— 全部逻辑：接口调用、照片压缩、渲染
- `manifest.webmanifest` —— 装到主屏幕用的信息
- `sw.js` —— 离线缓存。**只缓存外壳，不缓存照片**
- `offline.html` —— 断网兜底页
- `icons/` —— 图标

## 本地预览

```bash
npx wrangler dev --config api/wrangler.toml
```

Worker 同时托管前端和接口，打开它给出的本地地址即可。

⚠️ iPhone 上要"添加到主屏幕"必须用 **HTTPS** 地址，`file://` 和局域网 http 都装不了 PWA。

## 装到 iPhone

1. Safari 打开 https://prettier-sync.nutriflow.workers.dev （必须是 Safari，Chrome 装不了）
2. 分享 → 添加到主屏幕
3. 打开，填同步地址和口令，之后不用再填

## 记一条的流程

选图 → 自动压到长边 1600px → 填日期/光线/素颜还是带妆/四项评分/备注 → 保存。

几个已经踩过坑后加的东西：

- **日期自动按第一张照片的拍摄时间填**，不是填今天。
  之前手工记录时把 3 月的证件照记成了当天，就是因为默认值是今天。
- **同一次观察的多张照片放一条记录里**（比如左右脸），不拆成两条。
- **素颜/带妆是必选项**，因为带妆照判读不了色斑，不能和素颜照比分数。
- 评分**没看清就别填**，不要为了凑满而猜。

## 改了外壳之后

把 `sw.js` 里的 `VERSION` 加一，否则装过的设备会一直用旧缓存。

## 目前不支持

- 离线新增记录（保存必须联网，断网会明确报错，不会假装成功）
- 在 app 里编辑或删除已有记录（只能新增；删除得用接口）
- 产品与仪器建档（数据结构留好了，界面还没做）
